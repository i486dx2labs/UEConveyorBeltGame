# Conveyor Belt Game

## Overview

- This is the example project for the [Conveyor Belt System](https://www.fab.com/listings/36a4d23d-49c6-4e8b-aa64-751bcd447df9) plugin for Unreal Engine 5.3+.
- For this project to work, you need to have purchased and installed the plugin to the target Unreal Engine installation.
- Checkout this [page](https://dev.epicgames.com/documentation/en-us/unreal-engine/working-with-plugins-in-unreal-engine#installing-plugins-from-fab) to learn more about the installation process.
- This project uses Unreal Engine 5.3, but you can upgrade it to another version (downgrading is not possible though): right-click the `.uproject` file and select `Switch Unreal Engine version`.
- Before launching the project, right-click the `.uproject` file and select `Generate Visual Studio project files`.
- When opening the `.uproject` file, rebuild the modules when you're asked to do so.
- The full documentation can be found in the [Wiki tab](https://github.com/i486dx2labs/UEConveyorBeltGame/wiki).

## Branches

* `main`: targets the latest released plugin version.
* `develop`: targets the latest unreleased plugin version.
